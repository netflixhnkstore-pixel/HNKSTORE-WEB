# HNKSTORE Project 2 — Website + FastAPI

Project 2 is intentionally separated from the Telegram bot project.

Routes:
- `/` — HNKSTORE buyer website demo
- `/admin` — HNKSTORE admin demo
- `/api/health` — API health check

Important:
- This package does NOT contain bot.py, orders.db, users.db, or any Project 1 database.
- The current website is the approved visual/demo layer. It still uses its demo browser state.
- The next integration stage will connect this API to the bot through a controlled API/bridge. Do not copy the Project 1 database into this project.
